불러오면 지금 이 컴퓨터의 진행 상황은 저장 파일 내용으로 바뀌어요.

🏝️ 나만의 섬 생활
  • ←↑↓→ / WASD 이동
  • Space 앞에 있는 것과 상호작용
    나무 → 흔들기 · 물 → 낚싯대 던지기 · 너구리/상점 → 사고팔기 · 새싹 → 물 주기 · 거울 → 옷장
  • 🦋 풀밭의 곤충 앞에서 Space → 곤충 채집
  • ✦ 땅에 반짝이는 X 표시 앞에서 Space → 땅 파기 (화석·보석·벨 주머니!)
  • 🎮 오락기 앞에서 Space → 과일 받기 미니게임
  • 🎨 T 또는 [집 꾸미기] 버튼 → 집 벽지·바닥 테마 바꾸기
  • 🤍 치이카와 · 🐱 하치와레 · 🐰 우사기 · 🐿️ 모몽가 · 🦦 랏코에게 Space로 말을 걸면 미션을 줘요. 머리 위 ! = 새 미션, ★ = 완료 가능
  • 🏠 집 문 앞에서 ↑ 또는 Space → 집에 들어가기, 집 안 아래쪽 문으로 나가기
  • 🎣 낚시: 찌가 쑥 가라앉고 "!"가 뜨는 순간 Space! 너무 빨라도, 늦어도 도망가요
  • 🌊 바다와 연못에 사는 물고기가 달라요
  • 🌳 나무는 흔든 뒤 30초가 지나야 다시 뭔가 떨어져요 (가끔 벌집 주의!)
  • 🪑 아래 아이템 칸에서 가구·씨앗을 고르고 빈 바닥을 보며 Space → 설치 (섬, 집 안 모두 가능)
  • 📐 가구는 실제 크기만큼 칸을 차지해요 (소파 3칸, 침대 2×3칸…). 바라보는 방향으로 펼쳐지고, 빨간 칸이 보이면 자리가 부족한 거예요. 러그는 밟고 다닐 수 있고 그 위에 가구를 놓을 수 있어요
  • R 앞에 있는 가구·꽃 회수   Esc 손에 든 것 내려놓기
  • 🌷 씨앗은 물을 줄 때마다 한 단계씩 자라요 (씨앗 → 새싹 → 봉오리 → 꽃)
  • C 옷장(성별·머리·옷 바꾸기)   H 도움말   M 소리
  • 💬 / 또는 [채팅] 버튼 → 친구들과 채팅 (같은 방 이름으로 입장) · 채팅 중 Esc → 게임으로

진행 상황은 이 브라우저에 자동 저장돼요. 다른 컴퓨터로 옮기려면 [💾 저장 파일] 버튼을 쓰세요.
